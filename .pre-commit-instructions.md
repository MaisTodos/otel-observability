# Pre-commit Hooks

Este projeto usa [pre-commit](https://pre-commit.com/) para garantir qualidade de código antes dos commits.

## Instalação

### 1. Instalar pre-commit

```bash
# Com Poetry (já está nas dependências dev)
poetry install

# Ou com pip
pip install pre-commit
```

### 2. Instalar os hooks

```bash
pre-commit install
```

Isso instalará os hooks do Git que rodarão automaticamente antes de cada commit.

## Uso

### Executar manualmente em todos os arquivos

```bash
pre-commit run --all-files
```

### Executar apenas nos arquivos staged

```bash
pre-commit run
```

### Pular os hooks (não recomendado)

```bash
git commit --no-verify
```

## Hooks Configurados

- **ruff (linter)**: Verifica e corrige problemas de linting
- **ruff (formatter)**: Formata o código automaticamente
- **trailing-whitespace**: Remove espaços em branco no final das linhas
- **end-of-file-fixer**: Garante que arquivos terminem com nova linha
- **check-yaml**: Valida arquivos YAML
- **check-json**: Valida arquivos JSON
- **check-toml**: Valida arquivos TOML
- **check-merge-conflict**: Detecta conflitos de merge
- **debug-statements**: Detecta imports de debugger

## Comandos Úteis

### Atualizar hooks para versões mais recentes

```bash
pre-commit autoupdate
```

### Desinstalar hooks

```bash
pre-commit uninstall
```

## Configuração

A configuração está em `.pre-commit-config.yaml`. Para modificar os hooks, edite este arquivo.
